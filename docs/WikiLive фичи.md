# WikiLive: шаблон фич

Чек-лист обязательного и дополнительного функционала (экспорт из шаблона хакатона).

## Обязательные

| № | Функционал | Тип |
|---|------------|-----|
| 1 | Интеграция с MWS Tables через API | обязательная |
| 2 | Создание и редактирование вики-страницы в сценарии MWS Tables | обязательная |
| 3 | Вставка существующей таблицы MWS Tables в тело страницы (встраивание, не только ссылка) | обязательная |
| 4 | Автосохранение при редактировании и восстановление после перезагрузки / возврата (в т.ч. локальный кеш) | обязательная |
| 5 | Slash-menu для быстрого добавления блоков | обязательная |
| 6 | Горячие клавиши для slash-menu / ключевых команд редактора (перечень в README) | обязательная |
| 7 | Ссылки на другие страницы и обратные ссылки (backlinks) | обязательная |
| 8 | Совместная работа над документом (проверяемый сценарий) | обязательная |
| 9 | Редактор на open-source основе, permissive лицензия (MIT-like) | обязательная |

| 16 | Встраивание внешних элементов (виджеты, превью и т.д.) | дополнительная |
