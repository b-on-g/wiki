## 0. Введение

MWS Tables — это универсальный no-code инструмент для совместной работы с электронными таблицами.

MWS Tables похож на гибкую и простую в использовании базу данных. В ней можно легко связывать любую информацию и данные вместе для создания удобных и прозрачных пользовательских рабочих процессов.

**Функциональность:**

- Умные таблицы
- Формы
- Страницы
- Представления
- Шаблоны
- Конструктор ролей
- Автоматизации

## 3. Представления

Главный объект в MWS Tables — это таблица. На основании таблицы можно строить различные типы представлений; на текущий момент доступно 7 типов.

Представление — это способ организации и отображения данных. Оно позволяет настраивать, как именно вы хотите видеть свои записи, фильтровать их и сортировать по различным критериям.

Важно знать, что представления в MWS Tables не равны листам в Excel: данные используются одни и те же, меняется лишь их внешний вид.

### Типы представлений в MWS Tables

**Сетка** — по сути та же таблица, только её можно настроить под требуемый вам вид с помощью верхней панели инструментов.

Пример настройки: [видеоурок](https://memory.mts.ru/s/YHo1HnfrFkerCp-IWtI9Ew).

**Канбан-доска** — представление, позволяющее группировать данные для эффективного управления рабочим процессом.

Пример настройки: [видеоурок](https://memory.mts.ru/s/YHo1HnfrFkerCp-IWtI9Ew), [памятка Kanban (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/06/fc410fede244494ca18b89afcf304463/4_Kanban-board.pdf).

**Диаграмма Ганта** — инструмент управления проектами, который показывает последовательность выполнения задач с течением времени.

Пример настройки: [видеоурок](https://memory.mts.ru/s/oTrQLytFd0iRL0B1SOM5DA).

**Форма** — инструмент для организации совместной работы, быстрого сбора информации; с его помощью можно проводить опросы, собирать данные и заявки от пользователей.

Пример настройки: [видеоурок](https://memory.mts.ru/s/FHH5qPzsq0yThOODUgYRqg), [памятка Forms (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/06/278bc156088c4a05a6a50dae2c07a25a/7_Forms.pdf).

**Календарь** — представление, удобное для отслеживания сроков и планирования событий.

Пример настройки: [видеоурок](https://memory.mts.ru/s/oTrQLytFd0iRL0B1SOM5DA), [памятка Calendar (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/06/22c8fd0d37f14aad8c1485d05359964e/5_Calendar.pdf).

**Галерея** — представление, отображающее записи в виде больших карточек, например для визитных карточек, рекламных материалов, профилей сотрудников.

Пример настройки: [видеоурок](https://memory.mts.ru/s/neptypNutUK5HA3GvKhcZA), [памятка Gallery (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/06/6ac326386a364792a05e0cc75132b41b/6_Gallery.pdf).

**Архитектура** — представление, отображающее иерархические отношения данных. С его помощью можно создать организационную диаграмму, показывающую структуру компании.

Пример настройки: [видеоурок](https://memory.mts.ru/s/neptypNutUK5HA3GvKhcZA), [памятка Architecture (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/06/3afb8c40499841669b15ad6152daf7dc/6_Architecture.pdf).

## 4. Поделиться и зеркало

Бывают ситуации, когда нет необходимости приглашать коллег в пространство, но нужно поделиться с ними конкретными объектами пространства, например таблицей или папкой.

Для шаринга данных коллегам используются функции «Поделиться» и «Зеркало».

**В видеоуроке №8 вы узнаете:**

- как работают данные функции и в чём их отличие;
- какие привилегии могут быть настроены;
- как работать с файлами, чтобы они были доступны другим.

Для просмотра урока перейдите по ссылке: [видеоурок №8](https://memory.mts.ru/s/m_Ti7Dyw50Wv4CdH307dRg).

## 5. Виджеты и дашборды

Виджет — элемент, который позволяет визуализировать данные из таблицы в различных графических формах.

**Типы виджетов в MWS Tables:**

- Различные типы диаграмм — столбчатая, точечная и другие
- Сводная таблица
- Главное
- Воронка

Дашборд — отдельный элемент рабочего пространства, который содержит виджеты, отображающие важную информацию из таблиц в сжатом и наглядном виде.

**Видеоурок №9 включает в себя:**

- типы виджетов и их настройка;
- создание дашборда;
- импорт виджетов на дашборд.

Для просмотра урока перейдите по ссылке: [видеоурок №9](https://memory.mts.ru/s/ALwCeKTdnEmrXhx2nBqQCw).

Дополнительно можно скачать [памятку по работе с виджетами и дашбордами (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/17/d5508b1aa34f4eceb301a9d4aaf7970d/9_Dashboard.pdf) продукта MWS Tables.

## 6. Конструктор ролей

Кроме функций «Поделиться» и «Зеркало» можно настраивать персональные роли на уровне каждого объекта при помощи встроенного конструктора ролей.

Например, чтобы пользователь был участником пространства, но имел доступ только к одной папке, где хранятся нужные объекты.

**Роли по умолчанию:**

- `user`
- `admin`
- `owner`

Дополнительно можно настраивать кастомные роли.

**Доступны 5 основных уровней элементов, к которым можно выдать доступ:**

- Пространства
- Роли
- Таблицы данных
- Дашборды
- Папки

**Права, которые могут быть выданы пользователям:**

- Полный доступ
- Создание
- Просмотр
- Изменение
- Удаление

Для просмотра урока перейдите по ссылке: [видеоурок по конструктору ролей](https://memory.mts.ru/s/Y3LlkwdipUudEHXvTBmN8g).

Дополнительно можно скачать [памятку по работе с конструктором ролей (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/17/130353199ad447f2bf8974da368d0870/10_Roles.pdf) продукта MWS Tables.

## 7. Шаблоны и страницы

Шаблоны — это преднастроенная структура проекта под определённые задачи.

**Основные функции шаблонов:**

- использование готовых шаблонов для решения своих рабочих задач, тем самым не тратя время на первичную настройку;
- передача своих наработок коллегам/пользователям и их публикация.

Дополнительно можно скачать [памятку по работе с шаблонами (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/17/544e9c21ca754c6083dea575af33b5a2/11_Template.pdf) продукта MWS Tables.

Страница — текстовый редактор, который, помимо стандартных функций, обеспечивает возможность совместной работы нескольких пользователей.

**Возможности:**

- установка жирного/зачёркнутого/подчёркнутого текста и курсива;
- добавление заголовков 3 уровней;
- выравнивание текста по левому/правому краю и по центру;
- вставка нумерованного/маркированного списка, а также чек-листа;
- добавление изображений;
- добавление ссылок, блока кода и цитаты.

**Видеоурок №11 включает в себя:**

- навигация по шаблонам;
- создание своего шаблона;
- публикация шаблона;
- экспорт шаблона в виде файла;
- работа со страницами.

Дополнительно можно скачать [памятку по работе со страницами (PDF)](https://tables.mws.ru/attachment/spacespcdyvkrenkrj/2026/02/17/1eb94d1a15f24ec7828c41e5e8f07c69/11_Page.pdf) продукта MWS Tables.

Для просмотра урока перейдите по ссылке: [видеоурок №11](https://memory.mts.ru/s/DnbwjZqZDkK9aBp-Xi1H0w).

## 8. API

API продукта имеет достаточно простой интерфейс и низкий порог вхождения. Достаточно получить API-токен — тогда вы сможете использовать его для вызова эндпоинтов.

**Для получения API-токена:**

1. Перейдите в профиль пользователя в левой нижней части экрана.
2. Нажмите «Мои настройки».
3. Перейдите на вкладку «Разработчик».
4. Сгенерируйте токен или скопируйте существующий.

Пока вы находитесь в таблицах, вы можете найти вкладку API в разделе «Дополнительно». В ней будет показано, как можно вызвать те или иные запросы прямо на примере Ваших данных.

Для использования публичного API продукта вы можете воспользоваться [спецификацией](https://memory.mts.ru/s/folder/1U81b0Dex0WBSbV29uMdbw).

**URL для вызова запросов:** `https://tables.mws.ru/fusion/v1/`

**Параметры авторизации:** `Authorization: Bearer {your API Token}`
