# WikiLive (`bog/wiki`) — контекст для агента

## Отдельный проект

Модуль **`bog/wiki`** — это **самостоятельный проект** внутри MAM: приложение WikiLive вокруг сценария хакатона (вики + MWS Tables). В этом репо UI на **$mol/MAM**, сценарий данных — **Giper Baza**; в [`PRD.md`](PRD.md) рекомендованы React + Java как стек кейса — у нас **допустимый альтернативный** стек с обоснованием через интеграцию и воспроизводимый запуск. Не смешивай модуль с другими неймспейсами (`eve`, …) без необходимости: опирайся на стиль и зависимости `bog/wiki` и на PRD/доки этого каталога. Запуск Docker/Tauri — в [`README.md`](README.md).

## Правила для кода и репозитория

- Секреты (ключи MWS GPT, **токены Fusion/Tables** `Bearer usk***` и т.д.) — только в переменных окружения / секретах CI, **не** в исходниках и markdown. В `FUSION-API.yaml` в примерах бывают плейсхолдеры — не копируй их в код как реальные ключи.
- Стек и структура MAM/$mol — по необходимости см. общий skill MAM: `.agents/skills/mol/SKILL.md` в корне workspace.
